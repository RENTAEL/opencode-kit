# Video Motion and Pacing Components

Vocabulary for camera movement, pacing, transitions, and environmental motion in video generation prompts. Read this file only when assembling video prompts.

## Camera Movement

Always specify at least one; "Static" is a valid but explicit choice.

| Movement    | Keywords                                                   | Feel                              |
| ----------- | ---------------------------------------------------------- | --------------------------------- |
| Push in     | slow push-in, dolly forward, gradual zoom in, approaching  | Intimacy, focus, revelation       |
| Pull back   | pull-back, dolly out, reveal shot, zoom out, receding      | Context, scale, surprise          |
| Orbit       | orbit shot, 360 rotation, arc around, circling             | Showcase, drama, hero moment      |
| Tracking    | tracking shot, follow cam, steadicam, lateral movement     | Energy, journey, companionship    |
| Crane up    | crane up, rising shot, ascending, tilt up                  | Grandeur, hope, freedom           |
| Crane down  | crane down, descending, tilt down, settling                | Arrival, grounding, intimacy      |
| Static      | static shot, locked camera, tripod, fixed frame            | Calm, observation, tension        |
| Handheld    | handheld, slight shake, documentary feel, raw              | Authenticity, urgency, realism    |
| Fly-through | fly-through, FPV drone, immersive, soaring                 | Speed, exploration, freedom       |
| Pan         | slow pan left, pan right, horizontal sweep                 | Survey, landscape, passage        |
| Tilt        | tilt up, tilt down, vertical reveal                        | Scale, height, discovery          |
| Whip pan    | whip pan, fast pan, motion blur transition                 | Energy, surprise, time jump       |
| Rack focus  | rack focus, focus pull, shifting focus                     | Attention shift, depth, narrative |
| Dolly zoom  | dolly zoom, vertigo effect, zolly                          | Unease, realization, drama        |
| Crash zoom  | crash zoom, rapid zoom in, snap zoom, punch-in             | Impact, emphasis, comedy          |
| Camera roll | camera roll, rotating horizon, barrel roll, spinning frame | Disorientation, flight, dreamlike |

## Pacing / Rhythm

| Pace              | Keywords                                                | Duration guidance           |
| ----------------- | ------------------------------------------------------- | --------------------------- |
| Slow / Meditative | slow motion, gentle, lingering, meditative, unhurried   | 5–10s per scene, long holds |
| Medium / Natural  | steady, natural pace, smooth transitions, flowing       | 3–5s per scene              |
| Fast / Energetic  | fast-paced, quick cuts, energetic, dynamic, rapid       | 1–2s per scene              |
| Build-up          | starts slow, gradually accelerates, crescendo, building | Progressive shortening      |
| Burst             | sudden burst, explosive moment, then calm               | Contrast: 1s fast + 4s slow |

## Transitions

Use when the prompt implies multiple scenes or a time change.

| Type          | Keywords                                             | When                         |
| ------------- | ---------------------------------------------------- | ---------------------------- |
| Hard cut      | hard cut, jump cut, match cut                        | Action, energy, montage      |
| Fade          | fade to black, fade in, cross dissolve               | Time passage, ending, gentle |
| Wipe          | whip pan transition, wipe, swipe                     | Scene change, playful        |
| Morph         | morph transition, seamless blend, transform          | Object change, creative      |
| Invisible cut | hidden cut, masked transition, seamless scene change | Continuous take, smooth flow |

## Environment Motion

Add 1–2 of these to make scenes feel alive. Select what matches the setting.

| Element    | Keywords                                                                 | When to use                         |
| ---------- | ------------------------------------------------------------------------ | ----------------------------------- |
| Wind       | gentle breeze, strong wind, hair flowing, leaves rustling, fabric waving | Outdoor, emotional, dramatic scenes |
| Water      | calm waves, rushing river, rain falling, splashing, rippling reflection  | Nature, weather, mood setting       |
| Fire       | flickering flames, embers rising, smoke drifting, candlelight dancing    | Night, warmth, danger, fantasy      |
| Particles  | floating dust motes, snow falling, confetti, sparks, pollen, fireflies   | Atmosphere, magic, celebration      |
| Crowd      | bustling crowd, flowing traffic, busy street, people walking             | Urban, energy, scale                |
| Sky        | clouds drifting, timelapse sky, stars twinkling, aurora shifting         | Time passage, wonder, establishing  |
| Vegetation | swaying trees, grass rippling, flowers blooming, vines growing           | Nature, growth, serenity            |

## Subject Motion

Describe what the main subject is doing. Be specific about speed and style; keep one main action per short clip.

| Type         | Keywords                                                    | When to use                  |
| ------------ | ----------------------------------------------------------- | ---------------------------- |
| Human walk   | walking slowly, striding confidently, strolling, marching   | Character intros, journeys   |
| Human action | running, jumping, turning around, reaching out, dancing     | Energy, emotion, story beats |
| Vehicle      | driving smoothly, speeding, drifting, cruising, taking off  | Chase, travel, product shots |
| Object       | rotating slowly, floating, bouncing, shattering, assembling | Product showcase, abstract   |
| Animal       | galloping, flying, swimming, prowling, perching             | Nature, wildlife, dynamism   |
| Abstract     | morphing, pulsing, expanding, dissolving, materializing     | Titles, effects, transitions |

## Assembly Notes

- Always specify at least one camera movement (even "static shot" is a choice).
- Combine movement + pacing: "slow orbit shot, meditative pace".
- Add 1–2 environment motions for realism: "leaves rustling, dust motes floating".
- Keep subject motion singular and clear. One main action per 5s clip.
- For 3–5s videos: one camera move + one subject action + one environment detail.
- For longer videos: describe a sequence with transitions between segments.
