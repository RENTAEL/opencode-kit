# Language profiles

The governance model is language-agnostic. Profiles only suggest areas worth documenting.

## Agent / AI harness
Common areas: agent loop, sessions, memory, tools/permissions, skills/plugins/MCP, provider projection, context/compression, gateways, background jobs/concurrency.

## Python
Common areas: package/module boundaries, async/thread/process ownership, persistence, public APIs, typing, tests, packaging/tooling.

## Java backend
Common areas: application/service layer, domain model, persistence/transactions, API contracts, integrations/events, authorization, migrations, observability.

## Generic
Start with one `architecture/overview.md`. Split only when it becomes too broad to navigate efficiently.
