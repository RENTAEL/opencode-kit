# Project Anchor v0.1.0

Initial public release.

## Highlights

- Project truth model
- Significant change workflow
- Goal and Core Anchors
- Active Slice / Deferred execution control
- Failed-attempt learning
- Verification Evidence
- Completion Gate
- Reconciliation
- Lightweight governance CLI

Project Anchor is a thin governance layer for long-running AI coding work. It keeps coding agents aligned from intent through verified implementation without introducing an agent runtime or heavyweight project-management process.
