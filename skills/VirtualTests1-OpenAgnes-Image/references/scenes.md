# Scene-to-Style Matching

## Scene Context Recommendations

| Scene context | Recommended styles |
|---------------|-------------------|
| 天文/星图/星座 | Vintage Star Chart, Digital Star Chart, Sci-Fi Star Map |
| 人物/肖像 | Real Photo, Realistic Illustration, Anime, Sketch |
| 风景/自然 | Real Photo, Watercolor, Oil Painting |
| 动物 | Real Photo, Realistic Illustration, Pixel Art |
| 建筑/城市 | Real Photo, Minimalist, Cyberpunk |
| 产品展示 | Real Photo, 3D Render, Minimalist |
| 抽象/概念 | Surrealist, Minimalist, Sketch |
| 幻想/魔幻 | Fantasy Art, Surrealist, Oil Painting |
| 科幻/赛博朋克 | Cyberpunk, 3D Render, Sci-Fi |
| 复古/怀旧 | Vintage, Oil Painting, Pixel Art |
| 食物/美食 | Real Photo (appetizing), Watercolor, Realistic Illustration |
| 节日/庆祝 | Realistic Illustration, Oil Painting, Fantasy Art |
| 科技/UI/界面 | Minimalist, Cyberpunk, 3D Render |
| 教育/科普 | Realistic Illustration, Real Photo, Sketch |
| 时尚/穿搭 | Real Photo, Realistic Illustration, Sketch |
| 室内设计 | Real Photo, 3D Render, Minimalist |
| 游戏场景 | Fantasy Art, Cyberpunk, Pixel Art, 3D Render |
| 植物/花卉 | Watercolor, Real Photo, Oil Painting |

## Style Quick Descriptions

| Style | Chinese | Vibe | Best for |
|-------|---------|------|----------|
| Real Photo | 写实照片 | 真实、自然 | 产品展示、文章配图、肖像 |
| Realistic Illustration | 写实插画 | 精细、手绘感 | 书籍插图、品牌设计 |
| Anime | 动漫 | 日系、清新 | 角色设计、二次元内容 |
| Oil Painting | 油画 | 古典、厚重 | 经典题材、展览海报 |
| Watercolor | 水彩 | 柔和、通透 | 花卉、风景、文艺风格 |
| 3D Render | 3D渲染 | 立体、科技感 | 产品设计、建筑效果图 |
| Minimalist | 极简 | 简洁、留白 | UI、商务、现代风格 |
| Surrealist | 超现实 | 梦幻、奇异 | 概念艺术、抽象表达 |
| Pixel Art | 像素艺术 | 复古、8-bit | 游戏素材、怀旧风格 |
| Cyberpunk | 赛博朋克 | 霓虹、未来感 | 科幻题材、科技封面 |
| Fantasy Art | 奇幻艺术 | 史诗、魔幻 | 游戏原画、小说封面 |
| Sketch | 素描 | 黑白、线条 | 概念草图、艺术练习 |
