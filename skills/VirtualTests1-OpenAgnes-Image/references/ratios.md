# Aspect Ratio & Size Reference

> API 官方文档：建议将 `size` 与 `ratio` 配合使用。推荐 `size` 值为 `1K`、`2K`、`3K`、`4K` 档位。

## Supported Values

| Parameter | Supported Values |
|-----------|-----------------|
| `size` (档位) | `1K` · `2K` · `3K` · `4K`（也兼容 `1024x768` 等精确尺寸，但不支持的尺寸会被标准化） |
| `ratio` | `1:1` · `3:4` · `4:3` · `16:9` · `9:16` · `2:3` · `3:2` · `21:9`（默认 `1:1`） |

## Official Output Size Reference

> 以下为 API 的实际输出尺寸。非原生支持的精确尺寸（如 `1920x1080`）会被自动映射到最接近的标准档位和宽高比。

| Ratio  | 1K          | 2K          | 3K          | 4K          |
| ------ | ----------- | ----------- | ----------- | ----------- |
| `1:1`  | `1024x1024` | `2048x2048` | `3072x3072` | `4096x4096` |
| `3:4`  | `864x1152`  | `1728x2304` | `2592x3456` | `3456x4608` |
| `4:3`  | `1152x864`  | `2304x1728` | `3456x2592` | `4608x3456` |
| `16:9` | `1312x736`  | `2624x1472` | `3936x2208` | `5248x2944` |
| `9:16` | `736x1312`  | `1472x2624` | `2208x3936` | `2944x5248` |
| `2:3`  | `832x1248`  | `1664x2496` | `2496x3744` | `3328x4992` |
| `3:2`  | `1248x832`  | `2496x1664` | `3744x2496` | `4992x3328` |
| `21:9` | `1568x672`  | `3136x1344` | `4704x2016` | `6272x2688` |

## Use-Case Based Downstream Recommendations

> 以下为下游裁剪/缩放的目标尺寸。生成时请使用上表的档位+比例组合，再由下游调整到精确画布。

| Use case | Recommended ratio | Recommended API size | Downstream target |
|----------|-----------------|---------------------|-------------------|
| 📱 手机壁纸 | 9:16 | `2K` | `1472x2624` → 缩放至 `1080x1920` |
| 🖥️ 电脑壁纸 | 16:9 | `2K` | `2624x1472` → 缩放至 `1920x1080` |
| 📝 文章配图（横版） | 4:3 | `1K` | `1152x864` → 直接使用 |
| 📝 文章配图（方形） | 1:1 | `1K` | `1024x1024` → 直接使用 |
| 🖼️ 海报/打印 | 3:4 | `2K` | `1728x2304` → 缩放至 `1536x2048` |
| 🎬 视频封面 | 16:9 | `1K` | `1312x736` → 缩放至 `1280x720` |
| 👤 头像/Logo | 1:1 | `1K` | `1024x1024` → 缩放至 `512x512` |
| 📖 电子书封面 | 2:3 | `1K` | `832x1248` → 缩放至 `768x1152` |
| 📄 PPT 配图 | 16:9 | `2K` | `2624x1472` → 缩放至 `1920x1080` |
| 🎨 社交媒体帖子 | 1:1 / 4:3 | `1K` | `1024x1024` / `1152x864` |
| 🔄 通用/不确定 | 4:3 | `1K` | `1152x864` |

## Best Practice for Unusual Sizes

如果需要 `1920x1080` 或 `2560x1440` 等非原生尺寸：

```
→ 请求 size: "2K" + ratio: "16:9"
→ API 返回 2624x1472
→ 下游缩放至 1920x1080（16:9 比例一致，仅缩放不变形）
```

```powershell
python "config/opencode/skills/OpenAgnes-Image/scripts/generate.py" --prompt "..." --size "2K" --ratio "16:9" 2>&1
```
