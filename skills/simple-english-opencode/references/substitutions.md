# Substitutions

If a word carries no fact, delete it. Do not replace fluff with different fluff.

## Corporate / AI filler

| Cut or replace                    | Prefer                                 |
| --------------------------------- | -------------------------------------- |
| utilize, leverage                 | use                                    |
| facilitate                        | help, make possible                    |
| implement (vague)                 | do, start, build, run                  |
| prioritize                        | focus on                               |
| optimize (vague)                  | improve (say what)                     |
| functionality                     | function, feature                      |
| enables you to, allows you to     | you can                                |
| is designed to, aims to, seeks to | (delete; say what it does)             |
| in order to                       | to                                     |
| prior to                          | before                                 |
| in the event that                 | if                                     |
| due to the fact that              | because                                |
| with regard to, when it comes to  | for, about                             |
| a large number of                 | many / N                               |
| plethora, myriad                  | many                                   |
| as well as                        | and                                    |
| and/or                            | pick one, or "X, or Y, or both"        |
| e.g. / i.e. / etc.                | for example / that is / name the items |

## Empty intensifiers (usually delete)

simply, just, easily, seamlessly, effortlessly, truly, incredibly, remarkably, significantly (unless a number follows), very, really, extremely, quite, rather, basically, actually, literally

## Empty adjectives (delete or make concrete)

robust, powerful, comprehensive, performant, seamless, innovative, disruptive, cutting-edge, next-generation, best-in-class, enterprise-grade, world-class, holistic, impactful, scalable (unless you state the scale)

## Weak constructions

| Before                         | After                                   |
| ------------------------------ | --------------------------------------- |
| make a decision                | decide                                  |
| perform an analysis of         | analyze                                 |
| provide assistance             | help                                    |
| take into consideration        | consider                                |
| it is important to note that   | (delete; state the fact)                |
| it should be noted that        | (delete or name who notes it)           |
| some people say / studies show | cite or delete                          |
| circle back                    | follow up                               |
| deep dive / delve into         | read, examine, review                   |
| bandwidth (for time)           | time, capacity                          |
| learnings                      | lessons                                 |
| deliverables                   | work, results                           |
| stakeholders                   | people / team / customers (be specific) |

## Modal ladder

| Soft                              | Prefer                            |
| --------------------------------- | --------------------------------- |
| should (requirement)              | must                              |
| should (nice-to-have)             | delete, or state why it is better |
| may / might / could (possibility) | can                               |
| would (hypothetical)              | "If X happens, Y happens."        |

## Consistency locks

Pick one per document and keep it:

| Concept            | Pick one                                           |
| ------------------ | -------------------------------------------------- |
| checking           | check or verify or confirm or make sure            |
| configuration      | config or configuration or settings                |
| starting a process | run or start or execute                            |
| removing           | delete or remove (one meaning each if both needed) |
| problems           | error (defects) / failure (failed runs)            |
| showing            | show or display                                    |
