# Changelog - Django Dev Pro

Todos los cambios notables en este proyecto se documentan en este archivo.

## [1.0.0] - 2026-05-07

### Agregado
- ✅ Project Detector - Detección automática de proyectos Django
- ✅ Pattern Analyzer - Análisis de patrones del proyecto
- ✅ Model Generator - Generación automática de modelos
- ✅ Serializer Generator - Generación de serializers duales (Write + Read)
- ✅ View Generator - Generación de ViewSets REST
- ✅ Test Runner - Ejecución y análisis de tests
- ✅ Command Registry - Gestión de configuración por proyecto
- ✅ Environment Management - Soporte para pyenv y .env.local
- ✅ Interactive Setup - Configuración interactiva en primera ejecución
- ✅ Multi-Project Support - Soporte para múltiples proyectos
- ✅ Global Command - Comando global `django-dev-pro`
- ✅ Comprehensive Documentation - README, INSTALLATION, ejemplos
- ✅ Installation Script - Script de instalación automática
- ✅ License (MIT) - Licencia MIT

### Características
- Agnóstica a cualquier proyecto Django en el workspace
- Auto-detección de estructura y patrones
- Generación de código siguiendo patrones del proyecto
- Ejecución y corrección automática de tests (nivel MODERADO)
- Documentación auto-generada
- Persistencia de configuración
- Manejo de entornos virtuales con pyenv
- Carga automática de variables de entorno

### Documentación
- README.md - Guía completa
- INSTALLATION.md - Instrucciones de instalación
- CONTRIBUTING.md - Guía de contribución
- SKILL.md - Definición del skill para OpenCode
- skill.yml - Metadata de la skill
- examples/usage_examples.md - Ejemplos prácticos

## Cómo Reporte Bugs

Si encuentras un bug, por favor:
1. Verifica que no esté ya reportado
2. Abre un issue con:
   - Descripción clara
   - Pasos para reproducir
   - Versión de Python y SO
   - Logs/errores

## Cómo Sugerir Características

1. Abre un issue con etiqueta `enhancement`
2. Describe el caso de uso
3. Proporciona ejemplos si es posible
